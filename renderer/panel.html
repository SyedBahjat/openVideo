    Teleprompter

    Your script floats at the top of the screen, right under your camera, so you keep eye contact. Only you can see it: it never shows up in the recording or in screen sharing.

    How to write your script
    • Write what you’ll say. A blank line starts a new paragraph.
    • # Intro is a section title.
    • [open the dashboard] is a note to yourself: shown small, never read or tracked. Works mid-sentence too.
    • Markdown files work as they are (> quotes and **bold** are cleaned up).

    How it scrolls

    Clicks go to the app behind it, so it never gets in your way. Turn it off to move, resize, or click a word to jump there.
    Off by default, so your script stays private. Turn it on to film a demo of the teleprompter itself. It turns itself off when you quit openVideo.

      Share with a link

      openVideo saves shared videos to your own GitHub account. No openVideo server ever holds your videos, it’s free, and they stay yours.

      For each video you choose the repo and whether it’s public (anyone with the link can watch) or private (only people with access to the repo on GitHub can watch).

      Approve openVideo on GitHub

      GitHub just opened in your browser. Paste this code there (it’s already copied), then click Authorize.

      If macOS then asks about “openVideo Safe Storage”, enter your Mac password and click Always Allow. That’s where openVideo keeps your GitHub sign-in, encrypted.

      Allow private repos

      To keep videos private, GitHub has to let openVideo create and upload to private repos. GitHub calls this the repo permission. openVideo only uses it for the repos it makes for your videos.

      You’ll approve it on GitHub with a short code, like when you first connected. Viewers of a private video sign in with GitHub, and only people with access to that repo can watch.
